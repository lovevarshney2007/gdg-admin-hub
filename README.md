# GDG On Campus AKGEC - Proximity 6.0 Admin Portal

Event Registration and Attendance Admin Hub for Proximity 6.0.

## Technology Stack
- **Frontend**: React + Vite + TypeScript + Tailwind CSS
- **Analytics**: Recharts
- **QR Scanner**: Html5-QRCode

## Environment Setup
Create a `.env` file in the root directory (refer to `.env.example`):
```env
VITE_API_BASE_URL=https://registration.gdgakgec.org
```

## Running Locally
```bash
npm install
npm run dev
```
