# GDG On Campus AKGEC - Byte Talks 2026 Admin Portal

Event Registration and Attendance Admin Hub for Byte Talks 2026.

## Technology Stack
- **Frontend**: React + Vite + TypeScript + Tailwind CSS
- **Analytics**: Recharts
- **QR Scanner**: Html5-QRCode

## Environment Setup
Create a `.env` file in the root directory (refer to `.env.example`):
```env
VITE_API_BASE_URL=https://proximety-7nt5.vercel.app
```

## Running Locally
```bash
npm install
npm run dev
```
